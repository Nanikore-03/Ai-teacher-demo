# AI คู่ครู (Prototype)

ต้นแบบแอปผู้ช่วยครู: ช่วยครูดูภาพรวมนักเรียน งานค้าง และได้คำแนะนำจาก AI เพื่อให้ครูมีเวลาดูแลนักเรียนมากขึ้น

**ลองใช้งาน:** https://ชื่อผู้ใช้.github.io/ชื่อ-repo/  (แก้ลิงก์ให้ตรงกับของคุณ)

## วิธีทดลอง
1. เข้าสู่ระบบ: กดปุ่ม "เข้าสู่ระบบ" ได้เลย (ไม่ต้องใส่ข้อมูลจริง)
2. หน้า HOME: กดการ์ด *วิชาที่สอน* (เพิ่มวิชาได้), *นักเรียน* (24 คน ค้นหาได้), *งานค้าง* (เพิ่มงานเอกสาร/งานดำเนินเรื่อง และกดเพื่อทำเครื่องหมายเสร็จ)
3. หน้านักเรียน: กดชื่อเพื่อดูรายละเอียด กด ✎ เพื่อแก้ข้อมูลและคะแนน แล้วกด ✓ ระบบจะวิเคราะห์ใหม่ทันที
4. กดวันที่ในปฏิทินเพื่อดูตารางของวัน และให้ AI เตรียมแผนการสอน (ตัวอย่าง)

## หมายเหตุ
- ข้อมูลทั้งหมดเป็น **ข้อมูลสมมติ** ไม่มีข้อมูลนักเรียนจริง
- ส่วน AI เป็นกฎอย่างง่าย (เช่น คะแนนต่ำกว่า 50% → แนะนำทบทวน) ยังไม่ได้เชื่อม AI จริง เวอร์ชันจริงจะใช้ Claude API ผ่าน backend ที่เก็บ API key อย่างปลอดภัย
- ข้อมูลที่แก้ไขเก็บในเบราว์เซอร์ของผู้ใช้เท่านั้น (localStorage)

## เทคโนโลยี
HTML + CSS + JavaScript ไฟล์เดียว (`index.html`) ไม่ต้องติดตั้งอะไร
